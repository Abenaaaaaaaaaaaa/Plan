# Plan

计划计时类微信小程序的高保真原型与 PRD。

## 这是什么

「计划计时器」是一个按计划记录每日学习时长的工具：设定每天的目标时长与计划区间，用计时页记录时长，再用列表 / 详情 / 汇总日历查看完成度。

当前仓库只包含**产品原型（纯静态 HTML）**与**PRD**，尚未进入工程开发。

## 在线打开

开启 GitHub Pages 后可直接在手机浏览器打开：https://abenaaaaaaaaaaaa.github.io/Plan/

## 本地打开

双击根目录的 `index.html` 即可，无需安装任何依赖，也不需要构建。

> 原型使用 localStorage 保存状态，并固定了演示日期 `2027-02-28`（计划第 120 天），均为原型演示数据，不影响产品逻辑。
